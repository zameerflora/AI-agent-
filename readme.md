Greenwish

This is a simple PHP-based web application that allows users to sign up, log in, and make their wishes come true in an interactive platform.  

# Project Structure
- `dbconnect.php` – Database connection file (MySQL).
- `green.php` – cover page + login + signup.
- `login.php` – User login backend.
- `signup.php` – User registration backend.
- `wish.css` – Styling for the website.
- `green.jpg` – Background/visual asset.
- `logo.png` – Logo.

# Features
-  User **signup & login** system.
-  **MySQL database connection** for storing user details.
- Custom **CSS styling** for a better user experience.
- Attractive **logo and design assets** included.
